                                    확인 전
                                

                                
모델 확인을 눌러 주세요.

                            

                            

                                
                                
                            

                            

                            
기본 주소는 http://127.0.0.1:11434입니다. 웹브라우저에서 차단되면 Ollama의 OLLAMA_ORIGINS에 현재 웹 주소를 허용해야 하며, 데스크톱 빌드는 로컬 IPC를 사용합니다.

ScholarAI와 별도의 일반 멀티턴 대화이며, 위의 LM Studio 연결 설정과 AI Studio API Key를 공유합니다.
