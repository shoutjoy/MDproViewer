TIDY 사용자 JS 추가·관리

직접 입력하거나 .js 파일을 업로드하세요. 저장한 기능은 메인 창의 TIDY 메뉴에 버튼으로 추가됩니다.

업로드한 코드를 아래 편집기에 불러온 뒤 확인하고 저장합니다.

아래 규격 프롬프트와 현재 코드를 AI Jena에 보내 TIDY용 함수로 수정합니다. 결과는 편집기에만 반영되며 확인 후 저장합니다.

API 키와 서버 주소는 메인 JENA 설정을 사용합니다. 모델 목록은 연결 성공을 보장하지 않습니다.

신뢰하는 코드만 추가하세요. 코드는 자동 실행되지 않으며, TIDY에서 해당 기능 버튼을 눌렀을 때 선택 영역 또는 문서 전체를 변환합니다. 실행은 10초 후 자동 중단됩니다.
저장 위치: inDB에는 항상 복구본을 저장합니다. 필요하면 SQLite와 GitHub에도 동기화합니다.
