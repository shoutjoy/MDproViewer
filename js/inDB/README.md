# inDB 모듈

브라우저 내부 저장소(`MarkdownProDB`)에만 해당하는 초기화, 저장, 동기화, 관리 UI를 이 폴더에서 관리합니다.

## 파일

- `inDB.js`: DB 버전과 object store 생성, 현재 문서 inDB 저장, 기능 데이터 동기화, 저장소 탐색·백업·삭제, 설정 카드와 모달 마크업
- `inDB.css`: inDB 저장소 탐색기와 미사용 이미지 정리 창 전용 스타일

## 연결 경계

- `index.html`은 `inDB.css`와 `inDB.js`만 로드합니다. 설정 카드, 열기 버튼, 푸터 버튼, 모달 마크업은 모듈이 삽입합니다.
- `app.js`는 편집기 상태와 공유 DB 연결 변수(`db`)를 유지하고, 실제 inDB 초기화·저장·관리 작업은 이 모듈의 함수/API를 호출합니다.
- 외부 기능은 전역 호환 함수 또는 `window.InDbStorage`를 사용합니다. 기존 인라인 버튼 호출 이름은 그대로 유지합니다.

`inDB.js`는 `app.js` 다음에 `defer`로 로드되어 편집기 전역 상태를 연결하고, `window.onload`가 실행되기 전에 API 등록과 설정 UI 삽입을 마칩니다.
